## How to read this archive

- **Repository** means the source is publicly accessible at that link.
- **Live site** means a deployment exists; it does not imply every page or integration is production-ready.
- **Prototype / in development** means scope, validation, or operational readiness may still be incomplete.
- **Planned venture** means the long-term direction is being built, not that the company has already launched at scale.

## Engineering standards

I want each project to be explainable, reproducible, and honest about its limits. The next refactor pass is focused on README quality, setup instructions, proof links, and explicit status—not adding new features to make the list look longer.

*Less noise. More proof.*
